# Contributing to CyberAI-Lab

Contributions that improve defensive analysis, code quality, documentation, tests, local parsers, accessibility, or provider compatibility are welcome.

## Development

1. Fork or clone the repository.
2. Create a Python 3.10+ virtual environment.
3. Install `requirements.txt`.
4. Run `python -m unittest discover -s tests -v`.
5. Keep changes small and documented.

## Security Boundaries

Do not contribute features whose primary purpose is credential theft, destructive actions, unauthorized persistence, malware delivery, evasion, or indiscriminate exploitation. Security features should support owned systems, labs, CTFs, defensive research, or explicitly authorized assessments.

Never commit secrets, real credentials, private assessment data, or sensitive target information.
