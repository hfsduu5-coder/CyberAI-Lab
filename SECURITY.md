# Security Policy

## Reporting a Vulnerability

Please avoid opening a public issue for a vulnerability that could put users at risk. Contact the repository maintainer privately with a concise description, affected component, reproduction details, and suggested mitigation when available.

Do not include real credentials, API keys, private assessment data, or sensitive target information in reports.

## Intended Use

CyberAI-Lab is intended for defensive security, education, CTFs, research, and explicitly authorized testing. The project does not grant authorization to test third-party systems.
